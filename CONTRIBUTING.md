# Contributing

HookStat uses small, goal-scoped changes and risk-based validation.

1. Read `AGENTS.md` and `dev_governance_files/PROJECT_CHARTER.md`.
2. Work from a fresh branch based on `origin/main` unless a goal says otherwise.
3. Keep changes inside the active goal and preserve the local-first/read-only runtime boundary.
4. Run focused tests while iterating; run the settled-candidate gates required by `QUALITY_GATES.md` once.
5. Do not commit raw personal Codex session content, prompts, tool payloads, credentials, or local HookStat databases.

Bug reports should include HookStat version, runtime/version, coverage class, and a sanitized minimal fixture when possible.
